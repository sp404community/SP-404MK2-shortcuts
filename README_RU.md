# Шорткаты Roland SP-404MK2

Парсим таблицы с шорткатами из официального мануала (на англ.), переводим и редактируем вручную некоторые тексты.

Публикуем как страницу в Telegra.ph, например: https://telegra.ph/sp404-hotkeys-11-11

Публикуем как Markdown страницу, пример: https://sp404.ru/SP-404MK2/shortcuts

## Как это работает

[Официальное руководство](https://www.roland.com/global/support/by_product/sp-404mk2/owners_manuals/) Roland SP-404MK2 в PDF (на англ.) содержит таблицы с полным перечнем всех (?) сочетаний кнопок и их функций. Надо скачать свежее руководство и сохранить PDF в подпапку `/pdf`. Имя файла проверьте в коде `main.py`

Функция `read_to_json()` парсит таблицы из PDF ([jsvine/pdfplumber](https://github.com/jsvine/pdfplumber)) и сохраняет в JSON файл. 

Затем данные из JSON прогоняются через автоперевод с помощью [Deepl API](https://www.deepl.com/en/built-with-deepl) и сохраняет двуязычные данные в новый JSON файл. Зарегистрируйтесь в DeepL, чтобы использовать их API в бесплатном режиме. Но для этого понадобится:
1. привязать кредитку, очевидно, зарубежную. С неё ничего не спишется, это разовая процедура.
2. использовать HTTP прокси для обращений к DeepL API, т.к. они не работают с IP из некоторых стран.

Далее стоит внимательно просмотреть перевод и местами вручную внести правки.

После этого можно опубликовать данные из JSON файла в виде страницы на [Telegra.ph](https://telegra.ph/) через их [API](https://telegra.ph/api). Заранее понадобится:
1. создать аккаунт с токеном в Telegra.ph через официального бота [@telegraph](https://t.me/telegraph)
2. под этим токеном создать страницу, содержание которой потом будет обновлять этот скрипт.

## Настройки
См. приложенный для примера `.env.example`, его надо скопировать в `.env` и внести реальные данные:
- `DEEPL_API_KEY` - ключ АПИ deepl.com для первода строк, понадобится один раз
- `PROXY` - адрес вашего HTTP прокси, если вы выходите в сеть в регионах, не поддерживаемых DeepL
- `TELEGRAPH_TOKEN` - токен аккаунта Telegra.ph, который имеет права редактировать следующую страницу
- `TELEGRAPH_PAGE_PATH` - путь к странице (то, что после `https://telegra.ph/`), которую обновит скрипт. Страница должна уже существовать.
